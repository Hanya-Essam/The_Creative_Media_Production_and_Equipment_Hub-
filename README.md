## The Creative Media Production & Equipment Hub

This is a Database Systems course project. We built a database for a media production company, the kind of place where clients book studio time, supervisors look after the studios, and a crew of professionals works on each project with the equipment it needs.

The repo has three parts. DDl.sql creates all the tables and relationships. DML.sql fills them with sample data and has the example queries. The Software Application Code folder is a small C# Windows Forms app that connects to the database, so you can add or delete clients and professionals, update project and studio status, and run a few reports, like which studios have been idle, which projects are inactive, and which skill is most in demand.

The full requirements and ER diagram are in "Requirements and Data Models.pdf".
